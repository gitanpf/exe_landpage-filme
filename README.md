# 💍 The Lord of the Rings - Landing Page

Uma landing page minimalista, elegante e responsiva dedicada ao universo de **O Senhor dos Anéis**. O projeto foi desenvolvido com foco em uma interface limpa, tipografia marcante e interações suaves, priorizando uma estrutura de código sólida e o entendimento real da lógica por trás de cada componente.

## 🚀 Tecnologias Utilizadas

*   **HTML5:** Estruturação semântica e acessível.
*   **CSS3:** Estilização personalizada com foco em design minimalista, paleta de cores sóbria e transições suaves.
*   **jQuery:** Implementação de interações, manipulação do DOM e comportamentos dinâmicos de forma leve.

> 📌 **Diferencial Técnico:** Para garantir a máxima estabilidade, independência de servidores externos e total controle do código, todas as bibliotecas e plugins foram configurados e carregados a partir de **arquivos locais**, evitando o uso de CDNs.

## 🎨 Design & Funcionalidades

O projeto adota uma abordagem **focada e minimalista**, onde cada elemento em tela tem um propósito claro:

*   **Estética Clean:** Uso estratégico de espaços, contraste nítido e paleta de cores inspirada na obra (tons sóbrios e elegantes).
*   **Navegação Fluida:** Transições e animações sutis via jQuery que guiam o olhar do usuário sem poluir a interface.
*   **Componentes Dinâmicos:** Carrosséis de imagens e validações de formulários perfeitamente integrados ao layout.
*   **Design Responsivo:** Interface totalmente adaptável para dispositivos móveis e desktop.
